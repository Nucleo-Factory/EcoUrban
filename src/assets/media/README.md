# Recursos multimedia

Deja aquí las imágenes y videos que usaremos en el sitio.

- Imágenes: `.jpg`, `.jpeg`, `.png`, `.webp` o `.svg`
- Videos: `.mp4` o `.webm`

Luego podremos referenciarlos desde la página usando rutas como:

```text
assets/media/nombre-del-archivo.webp
assets/media/nombre-del-video.mp4
```
